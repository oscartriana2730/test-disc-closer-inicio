# Test DISC del Closer · Nivel inicial · 1% Método NEO

Test interactivo para personas que van a empezar en ventas y no tienen experiencia. Las 24 situaciones son de la vida diaria, del trabajo y de cómo se imaginan vendiendo, y el resultado muestra su estilo natural (D, I, S, C) y por dónde empezar el entrenamiento.

Es una sola página (`index.html`), sin dependencias ni proceso de build.
